### မင်္ဂလာပါရှင် / ခင်ဗျာ 🙏
**သုတဓမ္မ ဉာဏ်စမ်း (Sutadhama Quizzie)** မှ နွေးထွေးစွာ ကြိုဆိုပါ၏။

ဤစနစ်လေးသည် သာသနာတော်ဆိုင်ရာ သုတဓမ္မစာမေးပွဲ ဖြေဆိုကြမည့် သံဃာတော်များ၊ သီလရှင်များ၊ ဓမ္မမိတ်ဆွေများနှင့် လူကြီးမိဘများ စာမေးပွဲမတိုင်မီ စိတ်အေးချမ်းသာစွာဖြင့် မေးခွန်းဟောင်းများကို အချိန်မရွေး၊ နေရာမရွေး လေ့ကျင့်ဖြေဆိုနိုင်ရန် ရည်ရွယ်၍ စေတနာသဒ္ဓါတရားဖြင့် ဖန်တီးထားခြင်း ဖြစ်ပါသည်။

---

### 🌟 အဓိက ထူးခြားချက်များ (Key Features)

- 🕊️ **မျက်စိအေးချမ်းစေသော ဒီဇိုင်း**
  - သင်္ကန်းရောင်၊ ပတ္တမြားညိုရောင်တို့ဖြင့် သာယာကြည်နူးဖွယ် မျက်စိမညောင်းစေရန် အထူးဖန်တီးထားပါသည်။
  - လူကြီးမိဘများ ဖတ်ရှုရ လွယ်ကူစေရန် စာလုံးအရွယ်အစားကြီးမားပြီး ရှင်းလင်းသော မြန်မာဖောင့် (Pyidaungsu & Padauk) ကို အသုံးပြုထားပါသည်။

- 📚 **အပိုင်းနှင့် အခန်းများ စိတ်ကြိုက်ရွေးချယ်နိုင်ခြင်း**
  - ဒီပလိုမာတန်းနှင့် ဝိဇ္ဇာဘွဲ့တန်းတို့၏ သင်ရိုးမာတိကာအတိုင်း မိမိလေ့ကျင့်လိုသော အခန်းများကို တစ်ခန်းချင်းဖြစ်စေ၊ အားလုံးဖြစ်စေ လွတ်လပ်စွာ ရွေးချယ်နိုင်ပါသည်။

- ⚖️ **မျှတသော မေးခွန်းအချိုးကျ စနစ်**
  - သင်ရိုးပါ အခန်းများ၏ မေးခွန်းအရေအတွက်အပေါ် မူတည်ပြီး အချိုးကျ အညီအမျှ ရွေးထုတ်ပေးသဖြင့် သင်ခန်းစာအားလုံး ခြုံငုံလေ့ကျင့်ခွင့် ရရှိစေပါသည်။

- 🧠 **စိတ်ဖိစီးမှုကင်းသော အဖြေစစ်ဆေးမှု**
  - ဖြေဆိုနေစဉ် အမှားအမှန် ချက်ချင်းပြပြီး စိတ်အနှောင့်အယှက်မဖြစ်စေဘဲ စာမေးပွဲစစ်စစ်ကဲ့သို့ အေးဆေးစွာ ဖြေဆိုပြီးမှသာ ရလဒ်နှင့် အဖြေမှန်များကို ပြန်လည်ဆန်းစစ်နိုင်ပါသည်။

- ☁️ **ပေါ့ပါးမြန်ဆန်သော Cloud စနစ်**
  - မေးခွန်းပေါင်း (၃,၇၀၀) ကျော်ကို စက်ထဲတွင် ဖိုင်ကြီးများ ဒေါင်းလုဒ်ဆွဲထားရန် မလိုဘဲ အင်တာနက်ဖြင့် တိုက်ရိုက် လွယ်ကူမြန်ဆန်စွာ ဆွဲယူဖြေဆိုနိုင်ပါသည်။

- 💌 **အကြံပြုချက်နှင့် ဆက်သွယ်ရန်**
  - အမှားပြင်ဆင်ရန် သို့မဟုတ် ပိုမိုကောင်းမွန်စေရန် အကြံပြုချက်များကို အက်ပ်အတွင်းမှ တိုက်ရိုက် ပေးပို့နိုင်ပါသည်။

### 📱 စတင် အသုံးပြုနည်း (Getting Started)

မည်သည့် နည်းပညာ သို့မဟုတ် ပရိုဂရမ်မှ ထပ်မံထည့်သွင်းရန် မလိုပါ။

1. ဤ Repository ကို ဒေါင်းလုဒ်ရယူပါ (သို့မဟုတ် Clone ပြုလုပ်ပါ)။
2. ဖိုဒါထဲရှိ `index.html` ဖိုင်ကို မိမိဖုန်း သို့မဟုတ် ကွန်ပျူတာ၏ Browser (Chrome, Safari, Edge, Firefox စသည်) ဖြင့် နှိပ်၍ တိုက်ရိုက် ဖွင့်လှစ် အသုံးပြုနိုင်ပါသည်။
